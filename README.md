## Project goal
Build an original, reproducible simulation in which a tabular Q-learning agent assigns arriving vehicles to one of three parking zones. The zones have different capacities and walking distances. Vehicles have different expected stay durations. The agent learns a policy intended to balance parking search effort, walking distance, congestion, and invalid assignments.

This is a simulation prototype, not a deployed parking system.

## Files
- `parking_env.py` — custom parking environment and reward function
- `rl_agent.py` — Q-learning implementation and baseline policies
- `run_experiments.py` — training, evaluation, CSV export, and plots
- `trained_q_table.pkl` — Q-table generated by the experiment run
- `results/summary.csv` — mean evaluation metrics by policy

- `project_abstract_50_words.txt` — short project abstract

## Environment and RL formulation
- **State:** three quantized zone-occupancy levels (each 0–3), vehicle stay category (0–2), and demand/time segment (0–2). There are at most `4^3 × 3 × 3 = 576` encoded states.
- **Action:** choose one of three parking zones. Full zones are masked during action selection; invalid actions are still penalized by the environment.
- **Reward:** for valid assignments, `r = 5 − 0.8S − 0.45W − 0.9C − D`, where `S` is simulated search time, `W` is walking distance, `C` is a congestion penalty, and `D` is a small expected-stay blocking cost. Invalid/full-zone choices receive −12.
- **Algorithm:** tabular Q-learning with epsilon-greedy exploration.
- **Baselines:** first available, nearest available, and least occupied.

## Setup
Python 3.10+ is recommended.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

## Run
```bash
python run_experiments.py
```
This trains the agent for 1,800 episodes, evaluates each policy over 150 seeded episodes, saves the learned Q-table, writes CSV files, and regenerates figures.

## Reproducibility
The training seed is `7`; evaluation seeds begin at `2000`. The environment uses only Python's standard library, while `matplotlib` is used for plots. Results may vary slightly if you change seeds or hyperparameters.

## Metrics
- `avg_search_time`: mean simulated search time among accepted vehicles
- `avg_walking_distance`: mean zone walking distance among accepted vehicles
- `avg_congestion_penalty`: average congestion penalty among accepted vehicles
- `acceptance_rate`: fraction of vehicle decisions accepted
- `invalid_action_rate`: fraction of decisions selecting a full zone

## Limitations and next steps
The environment is a simplified model. It does not use real campus parking data, does not model vehicle routes at individual-space resolution, and does not guarantee that learned policies outperform every baseline. The report therefore presents measured simulation results and discusses limitations rather than claiming real-world deployment performance.
